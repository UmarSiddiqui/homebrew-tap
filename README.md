# HeyMate Homebrew tap

```sh
brew install umarsiddiqui/tap/heymate
```

Installs the latest [HeyMate](https://github.com/UmarSiddiqui/heymate) release, the AI buddy that lives in your Mac's notch. HeyMate updates itself after that.

HeyMate isn't notarized by Apple, so the cask clears the download's quarantine flag after install, exactly like the [official installer](https://getheymate.vercel.app/install.sh) does.
